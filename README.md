# Ledgerlens Analytics

Εργαλείο ανάλυσης λογιστικών και χρηματοοικονομικών δεδομένων με αναφορές για Διοικητικά Συμβούλια.

- Φόρτωση Excel/CSV με αυτόματη αντιστοίχιση στηλών (η επεξεργασία γίνεται μόνο στον browser)
- 15 χρηματοοικονομικοί δείκτες και Altman Z''
- Budget έναντι πραγματικών με γέφυρα κέρδους
- Audit analytics στο 100% των συναλλαγών: διπλές πληρωμές, όριο έγκρισης, Σαββατοκύριακα, στρογγυλά ποσά, ακραίες τιμές, Benford
- Τάση και πρόβλεψη με διάστημα 95%
- Αυτόματη αναφορά ΔΣ και λειτουργία παρουσίασης

## Deploy

Ένα στατικό αρχείο (`index.html`) που σερβίρεται από Caddy μέσω `Dockerfile`. Στο Railway: σύνδεση του repo στο service, και το build γίνεται αυτόματα σε κάθε push στο `main`.
